Will It Rain in the Next 12 Hours?
==================================

A Python application that checks weather forecasts and predicts whether rain is expected in the next 12 hours using external API data. This project demonstrates API integration, JSON parsing, and conditional logic.

Features
--------

Fetches real-time weather forecast data from a weather API for a specified location. Analyzes the next 12 hours of forecast data to detect precipitation conditions. Returns a clear "Yes" or "No" answer with additional details like expected rainfall intensity. Handles API authentication, request parameters, and response parsing with proper error handling for network issues or invalid locations.
